# Java CLI To-Do List

This is a simple command-line To-Do List application written in Java. I built this project to practice Object-Oriented Programming (OOP), working with collections, and handling user input.

## Features

- Add new tasks.
- View all your current tasks.
- Mark tasks as completed.
- Error handling: the app won't crash if you type a letter instead of a number.

## How to run

Make sure you have Java installed on your computer.

1. Clone the repository:
   ```bash
   git clone https://github.com/ilyashulga13/Java-Todo-List.git
   ```
2. Navigate to the project folder:
   ```bash
   cd Java-Todo-List
   ```
3. Compile the Java files:
   ```bash
   javac *.java
   ```
4. Run the application:
   ```bash
   java Main
   ```

## What I learned

- How to create custom classes and objects (`Task` class).
- How to use `ArrayList` to store dynamic data.
- How to use `try/catch` to prevent the program from crashing on bad user input.
- How to use `@Override` to customize the `toString()` method.
